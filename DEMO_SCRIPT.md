# 3–4 Minute Judge Demonstration Script

**Opening (20 sec)**  
“We are HACKNCODE. DOCUSHIELD AI goes beyond OCR by comparing related documents, identifying inconsistencies, preserving evidence identifiers, and generating an investigation dossier.”

**Step 1 — Ingestion (40 sec)**  
Upload the two synthetic sample PDFs. Explain that each file is processed locally and assigned a SHA-256 hash.

**Step 2 — Extraction (40 sec)**  
Show extracted fields such as name, date of birth, document ID and address. Explain that extraction is a prototype using embedded PDF text and transparent field patterns.

**Step 3 — Contextual comparison (60 sec)**  
Open Findings & Correlation. Point out the deliberately conflicting name/address values between the synthetic records. Emphasize: “This is a discrepancy requiring review, not an automatic fraud verdict.”

**Step 4 — Dossier (40 sec)**  
Download the JSON/TXT dossier. Show document identifiers, extracted fields, discrepancy details and limitations.

**Step 5 — Safety & honesty (30 sec)**  
Explain that scanned-PDF OCR, advanced image manipulation localization, signature verification and LLM reasoning are future extensions, not claimed as implemented.

**Closing (15 sec)**  
“DOCUSHIELD AI transforms isolated text extraction into traceable, contextual document investigation with a human analyst in control.”
